What it does

Everything brew knows, at a glance.

BrewGUI reads your real Homebrew state and shows it the way macOS apps should — fast, native, and out of your way.

↑

One-click updates

Outdated formulae and casks surface automatically. Update one, or sweep them all, and watch progress live.

⌕

Search & install

Find any formula or cask, read its description and dependencies, and install without memorizing the name.

⌥

Leaves & cleanup

See which packages you actually asked for versus pulled-in dependencies, and reclaim space with a tap.

⎇

Taps & casks

Manage third-party taps and GUI apps in the same place as your command-line tools.

◎

Truly native

Built in SwiftUI to Apple's Human Interface Guidelines. It feels like it shipped with the system.

⊘

No magic

Every action maps to a real brew command. Nothing happens to your machine that you couldn't run yourself.

Same Homebrew. Less typing.

You already know what it does.
Now you can see it.

BrewGUI doesn't replace Homebrew or wrap it in a black box. It runs the same commands you'd type — and shows you the output as a list you can act on.

$ brew outdated
node (22.3.0) < 22.4.1
ripgrep (14.0.3) < 14.1.0
neovim (0.9.5) < 0.10.0

$ brew upgrade
==> Upgrading 3 outdated packages ✓
Get started

Up and running in under a minute.

01

Have Homebrew

BrewGUI is a front end for it. If you don't have it yet, install from brew.sh.

02

Install the app

Run brew install --cask mdhesi/tap/brewgui or grab the .dmg from Releases.

03

Open it

Launch BrewGUI. It reads your existing packages instantly — nothing to configure.
